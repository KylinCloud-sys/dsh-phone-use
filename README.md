# dsh-mi-phone-use

DeepSeek Harness 插件：在**后台**操控小米手机——截图、点击、滑动、输入。不用 adb，不用 root，手机端不装任何东西。

## 干什么用

把小米互联（跨屏协作 / 妙享桌面）的投屏窗口当成一块可操作的画布：

- **看**：截手机画面，画面没变化时自动不返回图片
- **点**：按百分比坐标点击、长按、滑动
- **写**：英文数字直接逐键输入，中文走剪贴板 + 长按粘贴
- **唤起**：`phone_wake` 后台启动/恢复小米互联并等待手机画面
- **批量**：一次调用串多步动作，执行完只回变化区域

## 为什么用它

| | adb | 人工 | 本插件 |
|---|---|---|---|
| 需要开启调试 / 装驱动 | 是 | — | 否 |
| 会抢走鼠标和焦点 | 否 | 是 | 否 |
| 能一次串多步、按需回图 | 需自己写 | 否 | 是 |
| 模型能自己判断点没点中 | 否 | — | 是（`verify`） |
| 有权限闸门防止误操作 | 否 | — | 是（三档） |

适合：让 AI 代你在手机上点几下、看一眼、填个表、翻个页，而你还在用电脑干别的。

## 安装

> **建议先装简体中文 OCR 语言包**：插件靠读投屏画面上的文字（「正在连接」「加载失败」「手机解锁」）判断状态。没装的话自动唤起功能会受限，`phone_wake` 会返回 `ocrAvailable:false` 和安装指引。
>
> 安装方式：Windows 设置 → 时间和语言 → 语言和区域 → 添加语言 → 中文(简体) → 勾选「光学字符识别」。

前提：Windows 10/11、已装小米电脑管家（小米互联）并完成过一次与手机的配对/授权。**不需要填设备 ID 或任何配置**——插件会自己找到已连接的设备。

唤起流程（全自动）：以管家为父进程启动「妙享桌面」→ 纯后台恢复窗口 → 投递 `WM_ACTIVATE` 后点击启动器 → 由妙享桌面自己拉起「跨屏协作」→ 识别解锁页。全程不移动鼠标、不抢前台、不点锁屏/授权/配对按钮。它不能替手机完成首次配对或授权；唤起成功后，必须由主人在手机上手动指纹解锁。

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

然后**重启 DSH 并新建一个会话**（已存在的会话不会刷新工具清单）。

装好应看到四个工具 `mcp__miphone__phone_wake` / `phone_info` / `phone_see` / `phone_do` 和技能 `mi-phone`。

自检：

```powershell
node scripts/selfcheck.mjs        # 环境自检（会真的后台点一下屏幕中心）
powershell -File scripts/parse-check.ps1 scripts/mi-phone.ps1   # 只查 PowerShell 语法
node scripts/mcp-test.mjs         # 只测 MCP 握手与工具清单
```

（后两个是开发用工具，不跑也不影响使用。）

```powershell
node scripts/selfcheck.mjs
```

卸载：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall
```

## 怎么用

### 每次操作先唤起并解锁

AI 应先调用 `phone_wake`。成功返回 `unlockRequired:true` 并给出 `userPrompt`，这只表示 Windows 端画面已找到，不表示手机已解锁。AI 必须提醒主人：**请在手机上手动完成指纹解锁**，等待主人明确回复“已解锁”后，才调用 `phone_see` 或 `phone_do`。插件不会点击锁屏、授权、配对或确认按钮。

`phone_wake` 的 `state` 是判断"设备在不在身边"的关键：

| state | 含义 | 下一步 |
|---|---|---|
| `ready` / `restored` / `started` | 真实画面已就绪（非空白） | `unlockRequired:true`，请主人手动指纹解锁 |
| `screen-not-projected` | 窗口在，但画面纯空白 → 投屏没建立 | 多半不在同一局域网；让主人检查同网、手机端已开启小米互联。**此时不需要解锁** |
| `phone-not-found` | 连画面窗口都没有 | 设备不在附近或不在同一局域网 |
| `client-not-found` / `launch-failed` | 客户端缺失或启动失败 | 请主人安装/手动打开一次 |

`phone_see` 在画面空白时返回 `{"blank":true,"state":"screen-not-projected"}` 且**不回图片**，用来省 token：这种情况该提醒主人检查局域网，而不是催指纹解锁。

判据只看三个已知占位页（加载页 / 加载失败页 / 手机解锁页），**其余一律视为真实画面**——解锁后停在桌面还是某个 App 都不影响判断：

| 页面 | 特征 |
|---|---|
| 加载页 / 失败页 / 解锁页 | OCR 读到对应关键词 |
| 手机解锁页 | 蓝色插图包围盒 ≥ 30% 宽、15% 高，且有黑色标题 → `unlockPage` |
| 加载失败页 | 有蓝字但无大插图 → `errorPage` |
| 其余 | 主色占比 < 0.94 → 真实画面 |

### 中文输入是怎么实现的

中文走「剪贴板 + 长按菜单」，但**菜单不猜、不试**：

1. `openmenu` 写到剪贴板、长按输入框、把弹出的菜单裁成清晰图片返回（不点击任何菜单项）。
2. 模型看着这张图判断「粘贴」在哪，算好坐标，`tap` 一次点下去。
3. 截图确认字真的进了输入框，最后 `clip:"@restore"` 还原你的剪贴板。

为什么必须看图：每个 App、每个页面的菜单项数、顺序、宽度都不一样——见过「AI写作/粘贴/常用语」「粘贴/常用语」「问小爱/全选/剪切/复制/⋮」。所以不存在能写死的坐标。

已知限制：剪贴板同步到手机要几秒，太早长按菜单里不会有「粘贴」；菜单里没有「粘贴」时应重试一次，仍没有就如实报“没同步”，不会点「常用语」凑数。

### 已排除的路径（别再试）

- 直接向投屏子窗口投 `WM_CHAR` / `WM_IME_CHAR`：手机侧无反应。
- `SendInput(KEYEVENTF_UNICODE)` 注入 Unicode：焦点在手机画面也不进字。
- 全局 Ctrl 注入：会和你的物理键盘抢状态，默认禁用。

你那套「实体键盘敲拼音 → 电脑输入法选字 → 汉字进手机」走的是互联自己的键盘转发链路，不是窗口消息，插件没法在纯后台复现。维护者的完整踩坑记录见 [DEVLOG.md](DEVLOG.md)。

### 窗口恢复和剪贴板恢复不是一回事

`phone_wake` / PowerShell 的 `restore` 是恢复已经存在但最小化的小米互联窗口；`clip:"@restore"` 只恢复剪贴板内容。二者不要混淆。

```json
// 看画面
{"image":"auto"}

// 点一下，并确认这块区域真的变了
{"steps":[{"tap":"50,88"}],"verify":"20,80,60,15"}

// 输入中文（必须先点输入框，再给 at）
{"steps":[{"tap":"40,96"},{"text":"你好","at":"40,96"}]}

// 连续动作
{"steps":[{"swipe":"50,90>50,30","ms":300},{"wait":600},{"tap":"80,20"}]}
```

坐标都是**画面区百分比**（0-100），窗口移动、缩放、换分辨率都不影响。

点击后拿不准有没有点中，就带 `verify`：

- `hit:true` 点到了
- `hit:false` + `tries:2` 重试过一次仍没变，**没点到**
- `banner:true` 顶部弹了通知把页面挤位，结果不可信

## 权限

改 `config.json`，**即时生效，不用重启**：

```json
{ "permission": "auto" }
```

| 档 | 行为 |
|---|---|
| `full` | 不拦 |
| `auto`（默认） | 标了 `danger:true` 或落在 `dangerZones` 的步骤要你确认 |
| `ask` | 任何写操作都要你确认 |

被拦时工具返回 `need:"confirm"`，AI 必须停下来问你，你同意后它才能带 `confirm:true` 重调。

## 排错

| 现象 | 原因 / 处理 |
|---|---|
| 装了但没工具 | 一定要**新开会话**；旧会话的工具清单不会刷新 |
| `window not found` | 小米互联没开，或没投出手机画面 |
| 窗口标题不是「跨屏协作」 | 正常，那只是被流转的 App 名字；插件按窗口类名匹配 |
| 点击没反应 | 用 `verify` 判断；`banner:true` 说明被通知挤位了 |
| 中文没进去 | `at` 要给输入框坐标；菜单坐标不对时传 `menu` |
| PowerShell 报奇怪的语法错 | 编辑过 `.ps1` 后确认文件仍是 UTF-8 **带 BOM** |
